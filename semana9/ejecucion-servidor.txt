Al ejecutar el comando "node server.js", Node.js interpreta el script e inicializa el proceso del servidor backend, asignándole el puerto 3000.

En la terminal aparece el siguiente mensaje:
"Servidor ejecutándose en puerto 3000"

Cuando se visita la ruta "/estado" en el navegador (http://localhost:3000/estado), el servidor procesa la solicitud HTTP GET y responde con un objeto en formato JSON que contiene el estado actual del servicio:
{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
